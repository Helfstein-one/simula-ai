Simula-AI is an autonomous relational data mocking framework for Data Mesh ecosystems. It ingests a data contract YAML and uses an iterative CoALA cognitive loop (LangGraph + OpenRouter DeepSeek) with an isolated Pytest sandbox to generate consistent Faker generators, validation test suites, exported datasets, and interactive Mermaid ER diagrams.

Integrity mode: development

## Requirements

### R1. Cognitive Loop & State Management (CoALA Pattern)
Implement a LangGraph application structured around CoALA cognitive architecture in `core/`:
- `SimulaState` (`TypedDict`) containing `procedural_memory` (static rules for data engineering/faker/pytest), `working_memory` (`contract_yaml`, `generated_code`, `pytest_output`), `episodic_memory` (history of iterative errors and tracebacks), `iterations` count, and `status`.
- `internal_action_generate`: Queries OpenRouter (`https://openrouter.ai/api/v1`) using DeepSeek models (with fallback mechanism on HTTP 429). Includes robust regex parsing to strip `<think>...</think>` tags and extract clean python code blocks.
- `external_action_execute`: Pytest execution in a safe temporary subprocess sandbox (`simula_temp_test.py`) with strict timeouts. Captures stdout/stderr and return codes.
- `route_decision`: Loops on failure while `iterations < MAX_ITERATIONS`, terminates on success (status code 0) or max retries.

### R2. Dual Interface (CLI + Web UI)
- Interactive CLI using Typer and Rich: commands to load contracts, run the generation loop with live progress spinners, render logs, and export artifacts.
- Web UI using Streamlit: upload/edit contract YAML, live inspection of the LangGraph agent state/episodic memory, interactive Mermaid ER rendering, and data preview tables.

### R3. Hybrid Mermaid ER Diagram Generation
Generate a Mermaid entity-relationship diagram (`erDiagram`) for all mesh tables and foreign key relationships defined in the contract:
- Deterministic extraction directly from the contract YAML schema and foreign keys.
- Enriched with semantic cardinality and relational rule annotations generated by the agent.
- Renderable in Streamlit, printable to CLI, and saved to `output/mesh_er_diagram.mmd`.

### R4. Standalone Deliverables & Data Export
Upon successful Pytest validation (return code 0):
- Export standalone executable generator script: `output/generator.py`.
- Export accompanying Pytest suite: `output/test_mock.py`.
- Execute the generator to produce simulated datasets in `output/datasets/` in JSON, CSV, and Parquet formats.

### R5. Containerization with Podman
- Provide a rootless-ready `Containerfile` packaging Python dependencies, Podman execution entrypoint, CLI, and Streamlit Web UI.
- Include a sample data contract in `contracts/exemplo_credito_mesh.yaml` representing a multi-table credit mesh scenario (e.g., empresas, propostas, garantias, operacoes).
- Provide `.env.example` and documentation in `README.md`.
