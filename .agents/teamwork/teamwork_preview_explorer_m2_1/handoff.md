2. **Memory Systems (`core/memory.py`)**:
   - Observations (1.2, 1.7) require procedural rules for Faker (`pt_BR`, seeds, CNPJ, financial decimals, chronological timestamps), topological generation order (parent tables before child tables, zero orphan FKs), and Pytest assertions.

3. **LLM Client & 429 Cascade (`core/llm_client.py`)**:
   - Observations (1.4, 1.5, 1.7) demand OpenRouter connectivity with DeepSeek reasoning models, full jitter exponential backoff on HTTP 429, respect for `Retry-After`, and model fallback (`deepseek/deepseek-r1` -> `deepseek/deepseek-chat` -> `deepseek/deepseek-r1-distill-llama-70b`).
   - Observations (1.5, 1.7) also demand deterministic offline execution (`MockLLMClient`) supporting multi-iteration self-correction tests.
   - Therefore, `proposed_llm_client.py` implements both `OpenRouterClient` (with full jitter formula and fallback cascade) and `MockLLMClient` with a `fail_first_iteration` toggle.
